# wfc-mscomctl2 requirements

**Content type:** Project requirement index

Requirements are `REQ-NNNN` and test cases are `TC-NNNN`, numbered from 0001
in the namespace of this repository (see [docs/id-map.md](../docs/id-map.md)
for the identifiers that the controls had in the WFC repository). Each
requirement lists the test cases that verify it; each test case in
[tests](../tests) names the requirements it verifies. The check is
`scripts/Test-Traceability.ps1`.
